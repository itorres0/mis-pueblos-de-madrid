Estado de la aplicación

En desarrollo. Esta versión todavía no está publicada como una web instalable ni sincroniza automáticamente las visitas entre iPhone y iPad.

El mapa completo depende de la disponibilidad de los datos cartográficos. Si no se cargan los 179 municipios, puedes seguir utilizando las tres fichas de ejemplo.

Cuando se configure una cuenta para sincronizar, será necesario probar el acceso desde ambos dispositivos antes de registrar visitas reales.

Mis datos

Las visitas se guardan en este dispositivo. No hay sincronización automática todavía. Puedes exportar una copia e importarla en el otro dispositivo. Guarda la copia en Archivos/iCloud Drive para no perder tus visitas. La sincronización automática entre iPhone e iPad se incorporará al publicar la versión con cuenta.

Importante: esta versión no sincroniza automáticamente iPhone y iPad. Si borras los datos del navegador, podrías perder las visitas. Exporta una copia de seguridad.
